# 阶段 4 · 上架合规与提审自测

策划侧只需管"哪些设计会在提审时被拒"。结论统一用 ✅ / ⚠️ / ❌ 三级，并写明依据。政策会更新，落地前以国家新闻出版署与微信开放社区最新公告为准。

## 一、四条硬性前置

| 项 | 结论 | 说明 |
|---|---|---|
| 企业主体 | ❌ 个人不可注册小游戏 | 个人开发者只能做小程序或 H5，小游戏需企业/组织主体 + 微信认证 |
| 版号 | ❌ 无版号不可上线 | 国内上线的微信小游戏需提供版号；内购必须基于版号；执行细节以平台最新公告为准 |
| 软著 | ⚠️ 材料必备 | 常见为版号申报材料之一，名称须与游戏名一致；办理周期需提前排 |
| 实名与防沉迷 | ❌ 不可省略 | 需接入实名认证与未成年人保护机制（时长、时段、付费限制） |

## 二、功能完整性自测（最常被拒的一类）

- 提审版本必须**可完整游玩**，不能是"演示版""半成品"。
- 不得出现"敬请期待""功能开发中""敬请关注"作为主流程。
- 所有按钮可点，点击有响应；无空白页、无死链。
- 支付/广告能力若未开通，需隐藏对应入口，不能留不可用的付费按钮。
- 新用户首次进入即可完成一次核心玩法闭环（审核员不会玩很久）。

## 三、隐私与授权

| 项 | 结论 | 要求 |
|---|---|---|
| 隐私政策/指引 | ❌ 必须 | 在小游戏内可访问，说明收集哪些信息、用途、第三方 SDK |
| 授权时机 | ⚠️ 注意 | 先给玩法，后弹授权；不得启动即索取手机号/位置 |
| 最小必要 | ❌ 禁止 | 索取与玩法无关的权限（通讯录、精确位置等） |
| 第三方 SDK | ⚠️ 注意 | 广告/统计 SDK 需在隐私指引中披露 |
| 未成年人信息 | ❌ 禁止 | 不得未经监护人同意收集未成年人个人信息 |

## 四、内容安全

- 无违法违规、涉政涉黄、血腥暴力、赌博、迷信宣扬内容。
- 无未授权的 IP、字体、音乐、立绘、梗图（侵权是高频驳回原因）。
- 用户可输入内容（昵称、留言）需接入内容检测，并有举报入口。
- 若使用大模型生成对话：必须有输出过滤 + 人工复核机制，且不得生成未审内容。

## 五、素材与 IP 红线

| 情形 | 结论 | 处理 |
|---|---|---|
| 使用知名 IP 形象（动漫/影视/游戏角色） | ❌ 禁止 | 需正式授权，否则必拒 |
| 使用网络热梗图/表情包 | ❌ 禁止 | 权属不清，视为侵权 |
| 使用商用字体未授权 | ❌ 禁止 | 改用开源可商用字体 |
| 使用平台提供的正版素材 | ✅ 通过 | 仍需遵守其授权范围 |
| 原创或已购授权素材 | ✅ 通过 | 保留授权凭证备查 |

## 六、驳回原因库（按出现频率）

1. **功能不完整**：主流程走不通、按钮无响应、留"开发中"占位。
2. **无版号/资质缺失**：最常见的一票否决。
3. **隐私政策缺失或不可达**：首次启动未提供隐私指引。
4. **诱导分享/诱导关注**：分享才能继续、关注换奖励。
5. **侵权素材**：字体、音乐、立绘、IP。
6. **类目与实际内容不符**：选了不匹配的服务类目。
7. **广告违规**：强制插屏、误触诱导、关闭按钮过小。
8. **虚拟支付违规**：无版号开内购、外部收款。
9. **未成年人保护缺失**：未接实名或未限制时段/付费。
10. **测试信息残留**：调试按钮、内网地址、测试文案。

## 七、提审前自测清单

```markdown
[ ] 企业主体与微信认证已完成
[ ] 版号已取得（或确认无需的明确依据）
[ ] 软著名称与游戏名一致
[ ] 实名认证 + 未成年人时段/时长/付费限制已生效
[ ] 隐私指引在小游戏内可达，披露全部第三方 SDK
[ ] 启动不强制授权；授权前可玩
[ ] 主流程从新用户视角可完整走通，无占位文案
[ ] 所有按钮可点、有反馈、无死链
[ ] 无未授权素材（字体/音乐/立绘/IP）
[ ] 无诱导分享、无强制关注
[ ] 无虚拟支付入口（无版号时）
[ ] 广告关闭按钮清晰、插屏有间隔
[ ] 无调试入口、无测试数据、无内网地址
[ ] 名称、图标、简介与实际玩法一致
```

## 八、输出格式

```markdown
## 提审风险体检：<游戏名>
| 检查项 | 结论 | 依据 | 整改动作 | 责任方 |
|---|---|---|---|---|
| 版号 | ❌ | 未取得 | 签约出版单位申报 | 用户 |
| 隐私指引 | ⚠️ | 缺失第三方 SDK 披露 | 补广告/统计 SDK 条目 | 开发 |
...
最大驳回风险：<一条>
预计整改周期：<量级>
```

## 九、官方查证入口

- 国家新闻出版署：https://www.nppa.gov.cn/
- 微信开放社区（提审规范、驳回案例、版号要求公告）：https://developers.weixin.qq.com/community/
- 微信小游戏开发文档（运营规范、隐私、实名）：https://developers.weixin.qq.com/minigame/dev/guide/

不代申请、不伪造材料、不提供绕过审核的方法。需要法律效力背书时，建议咨询持证出版单位或专业法务。
